# 胶囊形状翻盖储物盒

## 产品概述

一个双圆形胶囊状储物盒，采用上下翻盖设计，通过铰链连接，磁铁闭合。适合存放小型物品如核桃、首饰、药品等。

## 核心要求

### 外形与尺寸

- **形状**: 双圆形胶囊造型，左右各一个圆柱形储物腔
- **整体尺寸**: 约 80mm × 46mm × 25mm（长×含外置铰链总宽×高）；胶囊主体宽 40mm
- **储物腔**: 每个圆形腔体直径约 35mm，深度约 20mm
- **壁厚**: 2.0mm（3D打印标准壁厚）

### 功能特性

- **翻盖机构**: 后侧外置三节打印铰链，通过金属销钉穿入；铰链轴位于盒体轮廓外，开合时不得与盒壁穿模
- **闭合方式**: 嵌入式磁铁闭合，确保盒盖不会意外打开
- **储物空间**: 双腔设计，可分类存放不同物品
- **表面装饰**: 光滑表面

### 制造方式

- **工艺**: FDM 3D打印
- **材料**: PLA
- **打印方向**: 盒体平放打印，无需支撑或最小支撑
- **装配**: 打印后装配磁铁和金属铰链销

### 材料清单

- **磁铁**: 4颗圆形钕磁铁，直径6mm，厚度2mm
- **铰链销**: 金属圆棍或销钉，直径约3mm（具体规格在CAD阶段确定）

## 使用场景

- 便携式药盒
- 首饰或小配件收纳
- 零食储物（核桃、坚果等）
- 桌面小物整理

## 设计约束

- 铰链必须支持至少1000次开合循环
- 磁铁吸力需足够保持闭合，但可单手打开
- 所有边角圆润，避免割手
- 内腔光滑，易于清洁
