45mm双腔比例放大的胶囊形上下翻盖双腔储物盒。闭合主体名义约102.86 x 51.43 x 41.14 mm，含外置铰链名义总宽约59.14 mm；缩放比例为45/35=1.285714。上下盖各约20.57 mm高，左右各一个名义直径45 mm的独立储物腔。上盖从正面半圆开槽所在的局部合模面开始，外壁保持直立约3 mm，超过该高度后才开始圆弧过渡并连续连接到顶部；不得在半圆槽附近提前起弧。上下盖内部两个圆形凹槽全部取消球面底部弧度，改为平面底面；底面与腔壁交界处只保留约0.8 mm小圆角，开口与壁的转角保持小圆润过渡，不得恢复球面底。上下盖合模改为周向阶梯式舌槽：下盖为连续周向凸舌，上盖为对应凹槽；名义咬合高度3.5 mm，允许范围3-4 mm，每侧保留约0.3 mm PLA装配间隙，舌槽不得侵入两个有效储物腔。后侧采用三节外置打印铰链：两个约10.29 mm下盖侧耳、一个约18.51 mm上盖中央耳，耳间轴向间隙各约0.39 mm，轴线Y=30.99 mm、闭合Z=20.57 mm；耳外径约9.64 mm，同轴销孔约4.24 mm。上下盖耳节必须采用同一套圆形轴套、椭圆根部和凸包过渡截面，并以合模面为镜像基准保持下盖与上盖转轴形状一致；销孔外必须为完整360度实体轴套，根部与壳体须有连续圆润、正体积承力连接，不得出现径向开槽、额外镂空、矩形颈部、独立方块或扇区补强、肩部、水平平台、薄舌片、细颈或可见阶梯。下盖耳根不得以向上坡面进入上盖闭合空间；下盖镜像根部最高点必须低于Z=20.57 mm合模面约0.51 mm，同时保持与后壁和完整轴套正体积融合。使用约直径3.86 mm、长度39.86 mm的金属销轴。上下盖各设一个固定直径8 mm、深3 mm的磁铁槽，磁铁中心Y=12.5 mm为当前设计默认位置，磁铁接口不随45 mm腔体比例缩放。正面闭合后形成约直径15.43 mm、深2.31 mm的完整圆形凹槽，圆心X=0、Z=20.57 mm，由下盖下半圆和上盖上半圆组成；删除旧中央直径1.8 mm小孔。PLA FDM，上下盖平放打印，最少支撑，外表面光滑，底盒下缘约2.57 mm圆角。闭合姿态用于检查合模、舌槽咬合与铰链扫掠，最终展示姿态约110度开盖。
